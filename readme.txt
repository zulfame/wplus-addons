Small, optional tools for WPlus UI and any WordPress site. Each tool can be switched off.

== Description ==

* Thumbnail generator (Tools > Thumbnail): make a cover picture with three layouts, your colors, logo and tags, and download it as WebP (the default, lighter and better for SEO) or PNG. Saving to the Media Library and the editor panel are coming.
* Light security hardening (planned): safe switches, a login attempt limit and a plain-language security check.

Open Settings > WPlus Addons to switch each tool on or off. The plugin sends nothing to any other site.
